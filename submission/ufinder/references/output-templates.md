# Output templates

Use these shapes. Every value must come from a real result. Write `not stated` when a file does not say. Each template ends with what was covered.

## Moments

| When | What | Files | Why grouped |
|---|---|---|---|
| Date and time range | Photos, recording, document | Real paths, up to 5 | Same time, same place |

## Dossier

**Subject:** the name the user gave.

**Key facts**

| Fact | Source | Page or time |
|---|---|---|

**Files by type:** documents, photos, recordings, videos, each with a count and real paths.

## Missing

| Mentioned name | Mentioned in | Checked |
|---|---|---|

## Expenses

| Date | Vendor | Reference | Amount | Currency | File |
|---|---|---|---|---|---|

**Totals:** one line per currency.

**Not included:** every file that failed, or had no amount.

## Contracts

| Next date | What happens | Parties | Notice | File and page |
|---|---|---|---|---|

## Recordings

**Decisions**, **Actions**, **Open questions**, each with the time in the recording. **Possible mishearing:** words to check.

## Digest

| Folder | New | Changed | Largest file |
|---|---|---|---|

**Ten most recent:** real paths with times.

## Events

| Time | Camera | Event | Files from the same time |
|---|---|---|---|

Say that a shared time does not prove a connection.

## Duplicates

| Group | Keep | Copies | Space saved |
|---|---|---|---|

## Coverage line

End every result with:

- Searched: services and scope that ran
- Not covered: services that failed, were skipped, or reported partial coverage
- Next: the useful follow-up functions
